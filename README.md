# VIM

Default branch is for vanilla configuration, check more out-of-box
configuration in other branches.

## INSTALL

See more help by checking `:h vimrc` in vim.

### unix

    git clone https://github.com/dalugm/vim.git ~/.vim

### Windows

    git clone https://github.com/dalug/vim.git ~/vimfiles

NOTE: This repo is for vim only, for neovim check this
[repo](https://github.com/dalugm/nvim).
